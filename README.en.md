# Cybersecurity Blog — HTML Practice Project

This is a hands-on practice project that brings together the HTML topics covered
so far (document structure, text formatting, links, lists, images, `div`/`class`/`id`,
tables, forms, and semantic tags).

## File

- `html-example-en.html` — a single-file HTML page that opens directly in the browser

## Topics used on the page

- Document structure: `<!DOCTYPE html>`, `<head>`, `<body>`
- Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Text formatting: `<h1>`–`<h3>`, `<p>`, `<strong>`, `<em>`
- Links: `<a href="...">`
- Lists: unordered (`<ul>`), ordered (`<ol type="1">`), description list (`<dl>`, `<dt>`, `<dd>`)
- Image: `<img>`
- `<div>` with `id` and `class` for grouping and styling
- Table: `<table>`, `<tr>`, `<th>`, `<td>`
- Form: `<form>`, `<input>` (text, email), `<select>`, `<textarea>`, `<button>`
- Inline CSS (`<style>`) for basic styling

## How to open

1. Open `html-example-en.html` in VS Code.
2. Click "Go Live" (Live Server extension) — the page will open automatically in your browser.
3. Alternative: double-click the file to open it directly in your default browser.

## Purpose

This file was created to practice the HTML topics covered during the W3Schools
HTML review, applying them all on a single page. The topic itself isn't real —
it was just chosen to fit a cybersecurity profile for practice purposes.
